# MAMUT Math

Librería Rust domain-agnostic para capacidades matemáticas reutilizables de los productos MAMUT. El workspace actual contiene `mamut-math-core` y `mamut-nsga3`; sensibilidad, gradientes, composición híbrida y WASM siguen sujetos a sus tickets y gates.

- [Análisis y preparación de subagentes](docs/planning/README.md).
- [DAG completo derivado de Notion](docs/planning/DAG.md).
- [Reglas operativas](AGENTS.md).
- [Contrato histórico de extracción](docs/extraction/EXTRACTION_CONTRACT.md).
- [Validación NSGA-III y límites históricos](docs/validation/VV001-REGRESSION.md).

Notion es la fuente canónica de scope, estados, dependencias y releases. La preparación local no inicia tickets ni acredita V0.1. El optimizador Hydraulics existente conserva la autoridad hasta aprobar su gate E2E.
